# Thư mục hình ảnh sản phẩm Scoby

## Cách thêm hình ảnh:

1. **Đặt hình ảnh vào thư mục này** với tên file như sau:
   - `tui-shopping-nho.jpg` (hoặc .png, .jpeg)
   - `tui-shopping-lon.jpg`
   - `tui-ca-nhan.jpg`
   - `tui-thuc-pham.jpg`
   - `quy-trinh-san-xuat.jpg`

2. **Kích thước khuyến nghị**: 800x600px hoặc 1200x800px

3. **Định dạng**: JPG, PNG, JPEG

## Cấu trúc thư mục:
```
frontend/public/images/
├── tui-shopping-nho.jpg
├── tui-shopping-lon.jpg
├── tui-ca-nhan.jpg
├── tui-thuc-pham.jpg
├── quy-trinh-san-xuat.jpg
└── README.md
```

## Lưu ý:
- Tên file phải chính xác như trên
- Hình ảnh sẽ tự động hiển thị trong carousel
- Không cần restart server, chỉ cần refresh trang web
